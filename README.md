# Adam Thorne — Technical Evidence Portfolio

Static Astro site for `adamthorne.com`.

## Local development

```sh
npm install
npm run dev
```

## Build and verify

```sh
npm run build
npm run verify
```

`npm run verify` builds the site and checks required routes, homepage claims,
project-page sections, metadata, and the public resume.

## Updating evidence

Project and experience content lives in `src/data/portfolio.ts`. Every
measurement must be traceable to a checked
resume, repository report, or reproducible benchmark. Use
`Measurement pending reproducible public benchmark.` when no publishable
measurement exists.

Do not add confidential employer data, customer names, geographic identifiers,
raw health records, internal URLs, or private source links. Private case studies
must use the disclosure language already present in the content source.
